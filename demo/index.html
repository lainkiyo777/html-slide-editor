HTML PPT Import Demo

Import an HTML deck, see its real rendering in the center, and control recognized content slots without moving the locked layout.

How to use

  1. Click Open fixture, import one HTML file, or choose Import Project Folder.
  2. Edit text or replace images in the right Slot panel.
  3. Use Display component to hide or restore a slot in the center preview.
  4. Click a Slot title to highlight its matching component, then use Undo/Redo when needed.
